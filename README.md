# ENOT Business Platform

Проект аналитической платформы для поиска и проверки бизнес-ниш в России и других странах. На текущем этапе репозиторий содержит инструкции для агентов, стандарты, шаблон задач и предварительную архитектуру.

1. Владелец или бизнес-советник готовит карточку по [шаблону](tasks/TASK_TEMPLATE.md).
2. Владелец выбирает роль в [AGENTS.md](AGENTS.md) и вручную передаёт задание со ссылкой на версию репозитория.
3. Агент читает свою инструкцию, выполняет задание и возвращает [отчёт](standards/reporting.md). Владелец принимает результат и решает, кому передать следующий шаг.

О продукте и этапах — [видение](strategy/vision.md), [дорожная карта](strategy/roadmap.md) и [обзор архитектуры](architecture/system-overview.md).
