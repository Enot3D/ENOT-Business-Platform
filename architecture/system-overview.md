# Предварительная архитектура продукта

Поток данных: разрешённый источник → извлечение и запись происхождения → нормализация → расчёт показателей → интерпретация ИИ → карточка ниши с проверяемыми ссылками.

| Компонент | Ответственность | Кандидат для обсуждения |
| --- | --- | --- |
| Сбор и анализ | Адаптеры источников, контроль качества, воспроизводимые расчёты | Python и pandas |
| Хранение | Наборы данных, наблюдения, ссылки, версии расчётов | PostgreSQL |
| API | Параметры исследования, статусы, карточки и источники | FastAPI |
| Веб-интерфейс | Фильтры, сравнение ниш, детализация и источники | Next.js и TypeScript |
| ИИ | Интерпретация на основе доказательств и проверка структуры вывода | Адаптер поставщика с версионируемыми промптами |
| Локальная среда и CI | Воспроизводимый запуск и проверки изменений | Docker Compose и GitHub Actions |

У наблюдения нужны источник, период, география, единица и дата извлечения. Расчёт хранит версию методики и ссылки на входные наблюдения. Интерпретация получает разрешённую выборку и возвращает выводы со ссылками на наблюдения. Размещение, выбор поставщика ИИ и способ фонового выполнения определяются после пилота по условиям доступа к данным, стоимости и ограничениям обработки.

Стек предложен для оценки. Его утверждение и реализация относятся к последующим заданиям владельца.
