# Интерфейс и состояния

Светлый аналитический SaaS с плотными таблицами на компьютере и последовательными карточками на телефоне. Акцент — действия и ссылки на доказательства. Типографика с табличными цифрами. Метки состояний содержат текст и значок; цвет дополняет значение. Формат RUB и дата обновления видны на карточке. Клавиатурный фокус, доступные названия кнопок, aria-live для результатов и возврат фокуса из панели источника входят в приёмку.

| Маршрут | Текстовая раскладка сверху вниз |
| --- | --- |
| /login | Название → логин и пароль → вход → общая ошибка авторизации |
| /niches | География и выпуск → фильтры (на телефоне раскрываются кнопкой) → счётчик → карточки с диапазоном, Confidence и покрытием → пагинация → панель сравнения |
| /niches/{id} | Название и география → диапазон и основания критерия → спрос / конкуренты / риски → таблица low/base/high и шесть стрессов → пробелы → действия сравнения и сохранения |
| /compare | Выбранные ниши → версия и география → интервалы на общей шкале → таблица по метрикам → пояснение ИИ → сохранение |
| /research | Список личных исследований → фильтры и дата → история сохранённых версий |
| /research/{id}/reports/{reportId} | Снимок параметров и версии → карточки/сравнение → доказательства → сохранённая интерпретация при наличии |
| Панель источников | Утверждение → тип → период/география → наблюдения → издатель, ревизия, дата доступа, статус, ограничения → URL |

Загрузка сохраняет раскладку и подписи. Ошибка API предлагает повторить запрос с request_id, 401 отправляет на вход с безопасным внутренним return path. 404 у личного ресурса показывает общий экран. Пустая география предлагает сбросить регион или выбрать РФ. У отсутствующей оценки, экономики или периода показывается «нет данных» с причиной; значение 0 остаётся числом. Недоступный URL помечается статусом и датой проверки, отображается сохранённое разрешённое основание при наличии. Для 2–5 ниш на телефоне — переключатель метрики или горизонтальная прокрутка с закреплённым названием строки. Интервалы пересечений видны; точность округления едина и не влияет на порядок.

ИИ отображает queued/running, готовый ответ, недостаток данных либо сбой и возможность повторного запроса. Базовая аналитика доступна во всех состояниях ИИ. Фильтры живут в URL, приватные данные и результаты остаются в серверном хранилище. Сохранение подтверждает номер версии; повторное открытие показывает дату исходного среза.
