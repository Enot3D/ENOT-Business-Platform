# Объём пилота

Выпуск включает 20 ниш скрининга по РФ из [TASK-002](../../research/TASK-002/market-overview.md), их экспертные баллы из [TASK-003](../../analysis/TASK-003/opportunity-score-v2.md), пять финансовых моделей (01–05) и реестр 30 проверенных на доступность URL. Аудит зафиксировал содержательный текст по 22 исходным URL. Доступность проверялась на дату аудита и не гарантирует пригодность конкретного утверждения.

Для конкретного региона показываются подтверждённые для этого региона карточки, если они появятся. Общероссийский выпуск и предложения локального пилота показываются с собственной географией. Выбор региона без покрытия даёт пустой результат и действие «Показать данные по России». Покрытие стран берётся из опубликованного выпуска. Фильтр бюджета использует нижнюю границу стартового диапазона: ниже неё карточка исключается, внутри диапазона показывается «возможен при нижней оценке», на верхней границе и выше — «покрывает диапазон». Ниши с неизвестным бюджетом по умолчанию исключаются при заданном бюджете и возвращаются с пометкой по явному переключателю. В отсутствие фильтра показываются все.

В MVP входят курируемый импорт, каталог, скоринг, сравнение, доказательства, сохранение и ограниченная ИИ-интерпретация. У 15 ниш финансовая модель отсутствует. Сценарии у остальных — допущения. У всех 20 пересекаются диапазоны v2, U и P не оценены, максимальный Confidence около 41/100. Сервис показывает приоритет проверки гипотезы, убыточность сценария или неопределённость по данным выпуска.

Следующий этап охватывает массовый поиск новых ниш, международные интеграции, потоки источников в реальном времени, продвинутые прогнозы, автономных исследователей, коммерческие подписки и платежи. Переход опирается на качество собранных наблюдений и решение владельца.
