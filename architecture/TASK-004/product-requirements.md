# Требования к MVP

Первый пользователь — владелец проекта, принимающий решение о следующем эксперименте по проверке спроса. Цель сценария — за один сеанс отобрать ниши из доступного набора, сравнить их по одной версии методики, проверить основания выводов и сохранить результат для повторного просмотра.

| ID | Требование |
| --- | --- |
| R1 | Каталог показывает доступную географию, отрасль и дату обновления выпуска. Фильтры по стране, региону, отрасли и бюджету в рублях. |
| R2 | Карточка показывает диапазон Opportunity v2, Confidence, покрытие, место, критерии, спрос, конкурентов, риски, экономику, чувствительность и пробелы. |
| R3 | Сравнение 2–5 ниш из одного выпуска и версии модели. Различия географии, единиц и отсутствующие поля видны. |
| R4 | Значимое утверждение ведёт к наблюдениям и версиям источников. Факты, расчёты, оценки и гипотезы маркируются. |
| R5 | ИИ объясняет результаты и предлагает эксперименты с трассировкой. При слабых данных показывает причины и вопросы для проверки. |
| R6 | Пользователь сохраняет параметры исследования и несколько неизменяемых отчётов, видит историю и повторно открывает отчёт. |
| R7 | Версии данных и методики прослеживаются. Пересчёт фиксируется с прежними входами либо создаёт отдельный результат на новом выпуске. |
