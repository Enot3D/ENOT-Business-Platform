# Формат и жизненный цикл задания

Используй [шаблон задания](../tasks/TASK_TEMPLATE.md). Имя файла — `TASK-NNN.md`. Владелец выбирает свободный ID по всем трём каталогам. У задачи одна назначенная роль из [AGENTS.md](../AGENTS.md). Для нескольких ролей оформи отдельные задачи и свяжи их ID.

- [backlog](../tasks/backlog/) содержит предложения и задачи, ожидающие назначения.
- [active](../tasks/active/) содержит задачи, вручную назначенные владельцем. Заблокированная задача остаётся здесь с описанием препятствия.
- [completed](../tasks/completed/) содержит принятые владельцем задачи со ссылкой на отчёт и версию результата.

Храни одну актуальную копию задания. Перемещай карточку после соответствующего решения владельца. Вне GitHub передай тот же текст, роль, ссылку на репозиторий и ветку либо SHA. Если доступ к репозиторию отсутствует, приложи корневую и персональную инструкции и нужные материалы. Входы должны быть доступны исполнителю, а каждый критерий должен описывать наблюдаемый результат. Укажи «нет» для отсутствующих зависимостей. При недоступном входе зафиксируй влияние, сделай доступную часть и передай владельцу конкретный запрос.
