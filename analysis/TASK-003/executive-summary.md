# TASK-003 — итог независимого аудита

**Роль** — Data Analyst. **Статус** — готово к приёмке владельцем. **Дата** — 12.11.2026 МСК. База — `cc00b7703b58341555591293bcb080f240b782d9`, ветка — `analysis/task-003-validation`. SHA результата и номер PR указаны в GitHub у этой ветки и в отчёте владельцу. [Карточка задачи](../../tasks/active/TASK-003.md).

## Выводы

- Все 20 баллов v1 совпали. Топ-5 остаётся **03, 04, 02, 05, 01** при исходных оценках. Высокие P4 у ЭПД и S5 у ручного аудита SKU не подкреплены наблюдениями. Исходное правило CAPEX для ничьих системно неприменимо, поэтому после E используются общие места.
- При 16 одиночных изменениях весов исходная пятёрка сохраняется, но лидер меняется в четырёх случаях. В 10 000 случайных сценариях 95,33% однозначно сохранили состав. №03 лидирует в 70,19%, №04 — в 29,81%. №01 остаётся в пятёрке с зачтённой частотой 95,595%, на пятую позицию также попадают №07 и №11.
- Все 15 вкладов и пять порогов безубыточности совпали. Снижение цены на 25% приводит к убытку у №01 и №02. После снижения базового объёма на 25% с округлением вниз четыре ниши выходят ровно на безубыточность. Котировок, реальных оплат и подтверждённых операционных результатов нет.
- Для 22 из 30 исходных URL доступен содержательный текст. Шесть не открылись, два вернули оболочку. У ФНС в S11 уже ноябрьский релиз, у АКИТ две ревизии одного 2025 года. Для WB комиссии относятся к графику воронки, а исходный URL указывает на другую локаль. Справки об ЭПД подтверждают правовой драйвер с исключениями. Из них нельзя получить продажи услуги.
- Opportunity Score v2.0-pilot сохраняет относительные веса семи критериев. Пропуски расширяют диапазон, качество наблюдений отражено отдельно в Confidence Score. По нижней границе порядок **03, 02, 05, 04, 01**, интервалы всех 20 ниш пересекаются. Ни у одной ниши нет достаточных свидетельств для оценки U и P. Максимум Confidence около 41/100.

## Выполненные проверки

Python 3.12.14 и pytest 8.3.5. `python3 run.py` выполнен дважды с побайтовым сравнением JSON. `python3 -m compileall -q .` и `uv run --with pytest==8.3.5 python -m pytest -q` прошли, 17 тестов. Проверены относительные ссылки, совпадение переписанных входов, состав Git diff и `git diff --cached --check`. Внешний доступ проверен веб-просмотром и повторным поиском с раздельной маркировкой результатов. Реальные API, платные кабинеты, лицензии на массовую выгрузку и пользовательские транзакции не проверялись.

Следующее решение владельца — определить оффер и географию пилота. Для пересчёта уверенности нужны сопоставимые альтернативы, измерения частоты и ущерба проблемы, предложения по цене и наблюдаемые оплаты с полной себестоимостью.
