# TASK-002 — выводы владельцу

**Статус:** исследовательский скрининг готов к приёмке; решение о нише и запуске теста принимает владелец. Россия, дата 12.11.2026. Исследованы [20 направлений](market-overview.md), [прозрачно оценены](scoring-methodology.md) и [разобраны пять](top-5-opportunities.md). [Источники](sources.md), [данные будущей платформы](platform-data-requirements.md).

| 2 | Аудит чистой маржи SKU | 70, средняя | Растёт общая торговля, есть отчёты и ограничения API (S02, S25–S28); бесплатные инструменты могут быть достаточны |

| 5 | Реверс-инжиниринг малых деталей | 62, средняя по наличию услуги, низкая по нашей оплате | Есть действующие предложения (S21); критичны точность, ответственность и реальная маржа |

Ближайший шаг: владелец выбирает **одну** нишу и географию для этапа 1 дорожной карты; рекомендуется начать с ЭПД как дешёвого сервисного теста и параллельно только подготовить неответственные примеры деталей ENOT для альтернативного пилота. Пороги go/stop и число контактов описаны в исследовании; интервью/оплаты не проводились. Для ЭПД проверить конкретные обязанности и конкурентов перед предложением услуги. Основные риски: насыщенные предложения крупных игроков, юридическая ответственность и персональные данные ЭПД, изменение API и качество себестоимости селлеров, качество деталей/КД, длинная B2B-продажа. Показатели общего рынка не дают объём рынка этих услуг. Показатель АКИТ за 2025 пересмотрен с 11,5 до 13,2 трлн ₽; не смешивать версии (S01–S02).

**Будущей платформе** нужны версия источника, период, география, единица, методика и статус утверждения; пересчитывать только сопоставимые ряды и явные сценарии. Боль клиента, конкуренцию по качеству, цены, платежи и юридическое применение проверить вручную. В первую очередь использовать открытые ФНС/Росстат и ручной журнал интервью; API ГИСП требует доступа, платные API не использовать.

**Ограничения:** нет интервью, тестов спроса, сделок ENOT, котировок CAPEX и независимых данных о марже. Все бюджеты и доходы — расчёты на вымышленных сценарных вводах. Выбор веса в рейтинге субъективен; различие баллов не статистически значимо. Исследование не меняет [стратегию](../../strategy/vision.md) и не запускает продукт.
