# Предварительная дорожная карта

| Этап | Результат для перехода |
| --- | --- |
| 0. Инструкции | Владелец проверил реестр ролей и вручную передал первую карточку |
| 1. Пилотное исследование | Выбрана одна ниша и география, собраны источники, проведена ручная оценка, описаны пробелы |
| 2. Проверка данных | Воспроизводимый набор данных с происхождением и пересчитываемыми показателями |
| 3. MVP для владельца | Пользователь проходит путь от параметров исследования до карточки ниши с источниками |
| 4. Оценка качества | Проверены воспроизводимость выводов, полезность отчётов, стоимость и ограничения ИИ |
| 5. Коммерческий пилот | После решения владельца проверены сценарии внешних пользователей и требования к запуску |

Этапы задают последовательность проверки гипотез. Ниша, даты и критерии запуска коммерческого пилота требуют решения владельца. TASK-001 покрывает подготовку документов этапа 0.
