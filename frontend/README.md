# ENOT Business Platform · Frontend

Next.js App Router, React и TypeScript. Каталог, сравнение, проекты, отчёты и интерпретации используют FastAPI TASK-005. Типы маршрутов и ответов генерируются из [OpenAPI TASK-004](../architecture/TASK-004/api-contract.yaml).

## Запуск

[Профили Compose и создание аккаунта](../docs/local-development.md#запуск-интерфейса-и-локального-аналитика). Для разработки без Docker запустите [FastAPI](../backend/README.md#запуск-и-интерфейс-для-task-009) на `127.0.0.1:8000`, задайте ему `APP_ORIGIN=http://localhost:3000` и локальный режим cookie. Команды запуска выполняются в `frontend/`.

```sh
npm ci
npm run dev
```

Браузер обращается к относительным `/api/v1/…` на том же origin. При необходимости задайте Next.js переменную `API_INTERNAL_ORIGIN` до запуска разработки или production-сборки. В Compose используется `http://api:8000`. Cookie сессии выдаёт API. CSRF-токен используется из памяти вкладки, а незавершённая запись повторяется с тем же ключом идемпотентности при тех же параметрах.

## Проверки

```sh
npm run generate:api
git diff --exit-code -- lib/openapi.d.ts
npm run lint
npm run typecheck
npm run build
```

Для сквозной проверки запустите профиль `web` и воркер, создайте одноразовый аккаунт в тестовом экземпляре и передайте его логин и пароль в `ENOT_E2E_LOGIN` и `ENOT_E2E_PASSWORD`. При другом порте укажите `ENOT_E2E_ORIGIN`. Тест создаёт и оставляет проекты в тестовой базе.

```sh
npx playwright install chromium
npm run test:e2e
```

В Chromium проверяются окна 1440×900, 768×1024 и 390×844. Сценарий покрывает вход, выдачу из 20 ниш, пустой регион, пороги бюджета, экономику и пробелы, клавиатурное раскрытие доказательства, сравнение, локальную сводку воркера, запись и повторное открытие отчёта. На компьютере дополнительно проверяется повтор записи после потери ответа.

## Границы пилота

- В каталоге видны данные и география опубликованного выпуска. Финансовые сценарии есть для пяти ниш. Остальные карточки показывают причину отсутствия.
- Аналитик TASK-005 возвращает локальную сводку или статус недостатка данных. Подключение внешнего провайдера относится к TASK-007.
- Подборка для сравнения хранится в памяти вкладки. Сохранённые отчёты, проекты и источники снимков хранятся на сервере.
- Название и дата в списке исследований фильтруют текущую страницу. Постраничная навигация использует серверный курсор.
