# TASK-009 — Локальное окружение и CI

- **Уникальный идентификатор** — TASK-009
- **Предлагаемый агент** — [devops](../../agents/devops.md)
- **Статус** — предложение, назначение ожидает решения владельца
- **Базовая версия** — main после приёмки TASK-004, SHA фиксируется при назначении

## Цель
Обеспечить воспроизводимый запуск и проверки PR.

## Контекст
Первый выпуск использует курируемые данные TASK-002/003, результаты сохраняются как снимки.

## Входные данные
[Профильная спецификация](../../architecture/TASK-004/system-design.md), [OpenAPI](../../architecture/TASK-004/api-contract.yaml), [план](../../architecture/TASK-004/development-plan.md).

## Порядок выполнения
1. Сверить контракт и зависимости, подготовить локальные фикстуры.
2. Подготовить свой результат и выполнить применимые проверки.
3. Передать PR и доказательства владельцу.

## Ожидаемый результат
Compose, GitHub Actions, инструкции запуска, миграций и восстановления локальной БД.

## Критерии приёмки
- [ ] Чистая среда стартует по инструкции; CI прогоняет проверку контракта и тесты без внешнего ключа.

## Ограничения
Работа начинается после назначения. Использовать локальные или разрешённые тестовые среды. Платные ресурсы и слияние требуют решения владельца.

## Зависимости
TASK-004 для подготовки; выходы TASK-005–007 для полной интеграции.

## Требования к отчёту
[Стандарт отчётности](../../standards/reporting.md), команды проверок, доказательства по критериям и пробелы.
